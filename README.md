# Estudos JavaScript

Exercícios e projetos práticos de JavaScript — lógica, DOM, ES6+ e outros tópicos — feitos durante minha trilha de estudos como dev backend.

## Estrutura

- **JS_Fundamentos/** — exercícios de lógica, sintaxe básica.
- **JS_Moderno/** — exercícios com recursos de ES6+ (arrow functions, destructuring, módulos, etc).
- **JS_POO/** — exercícios de Programação Orientada a Objetos (classes, atributos, métodos).

Novas pastas serão adicionadas conforme eu avançar em outros tópicos de JavaScript. Quando eu migrar para TypeScript, isso vai para um repositório separado.
